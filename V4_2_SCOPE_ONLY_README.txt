Isazi Herbal Shop Client Portal V4.2 – scope only, no project amount.

1. The fixed project amount is removed from owner dashboard, client progress,
   project scope/edit forms, and downloadable status PDFs.
2. Included features, exclusions, extra-services written-approval rules remain.
3. Automatic database migration removes the obsolete price from the ACTIVE
   project scope, creates a new version, and preserves historical revisions.
4. Invoices and monetary terms are still handled separately by ECS.
5. Product prices in demo storefronts are unchanged: these are product prices,
   not the removed website-development price.

Installation:
- Stop Flask with CTRL+C.
- Download ZIP to Downloads.
- Use the two-line PowerShell snippet supplied in chat (or script inside ZIP).
- Database backups happen automatically before files are replaced.
- Re-launch existing app after upgrade.
