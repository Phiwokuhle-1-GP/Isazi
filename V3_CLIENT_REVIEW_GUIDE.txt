ISAZI HERBAL SHOP / ECS CLIENT REVIEW MODULE (VERSION 3)

LOGIN
  Owner login: http://127.0.0.1:5000/login
  Username: owner (or your pre-existing admin account)
  Password: the private password you previously set; no default password is included.

NEW CLIENT PAGES
  Progress: http://127.0.0.1:5000/client/progress
  Designs:  http://127.0.0.1:5000/client/designs

CLIENT WALKTHROUGH
  1. Sign in using a viewer account created by the owner.
  2. Open Client progress to see nine clear delivery steps and their live status.
  3. Open Design catalogue and compare Botanical Classic / Premium Earth / Clean Modern.
  4. Open a concept, switch Desktop/Mobile, and post comments or change requests.
  5. ECS updates the formal status and plans next revisions.

ECS OWNER ACTIONS
  - Edit step text, assign owners, change status, attach evidence notes.
  - Add/edit design proposals and update a proposal's formal approval status.
  - Inspect History for the version and actor of each formal update.
  - Export all client comments as CSV; export plan+comments as JSON.

IMPORTANT FOR EXISTING INSTALLATIONS
  - Stop the previous server before upgrading.
  - Preserve and back up your ORIGINAL instance/ directory; do not overwrite it.
  - Start the new app. New modules are added to the existing database safely.
  - localhost access works only on the computer running the server.
  - Public client hosting requires HTTPS, WSGI and security hardening.

NOT YET FUNCTIONAL
  E-commerce orders, stock, payment gateway and live product checkout are still planned.
